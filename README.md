# Cristalix Pack Converter

Конвертер ресурспаков Minecraft 1.13+ в формат 1.12.2 — под клиент Cristalix.

- переименование текстур после «флаттенинга» 1.13 и поздних версий;
- исправление ссылок в моделях, `pack.mcmeta`, `lang`;
- сборка картин и брони обратно в формат 1.12;
- наглядный предпросмотр «было → стало» и ручные правила;
- пресеты соответствий для кастомных блоков Cristalix.

Работает в браузере, пак никуда не загружается.

## Разработка

```sh
npm install
npm run dev
npm test
```
